# Báo cáo kênh TikTok PG · OPPO MB2

Robot miễn phí đọc số TikTok của PG mỗi sáng 6h (giờ VN) và đưa lên trang kết quả: tổng khu vực, theo nhóm, video trên 1.000 view để làm mẫu, video dưới 300 view để kèm, đánh giá từng kênh.

- **Trang kết quả:** https://tienthincnn-code.github.io/kenh-tiktok-pg-mb2/
- **Cấu hình** (tên khu vực, hashtag, ngưỡng view): `cau-hinh.json`
- **Danh sách kênh PG:** `tai-khoan.csv` (2 cột `tiktok,nhom`) — KHÔNG ghi tên, số điện thoại, doanh số PG vì repo công khai.
- **Chạy tay:** tab Actions → "Quet TikTok PG" → Run workflow.
- Chi phí: 0đ (GitHub Actions + Pages miễn phí, yt-dlp mã nguồn mở). Robot chỉ đọc số công khai, không xem nội dung video.
- Mô hình gốc: Region Marketing Tiền Giang · Trang tổng toàn quốc: https://mrdt1988.github.io/dashboard-phu-kien/toan-quoc-pg.html
- Hướng dẫn PG làm kênh + 20 video: https://mrdt1988.github.io/dashboard-phu-kien/video-pg.html?v=6
